# Frequency Meter and Signal Generator (Raspberry Pi Pico)

Electronic instrumentation project consisting of a **dual-core embedded firmware in C** for **Raspberry Pi Pico (RP2040)** and a **desktop application in C# (.NET / Windows Forms)** for real-time visualization.

The system allows generating PWM signals from **0.01 Hz up to 120 MHz** and simultaneously measuring frequency, duty cycle, high/low times, and total event count.

## Key Features

### Firmware (Raspberry Pi Pico @ 240 MHz)
- **True Dual-Core Architecture:**
  - **Core 0:** USB-CDC communication management and signal generator control.
  - **Core 1:** Continuous signal acquisition, hardware counter management, and data transmission.
- **Hybrid Signal Generator (`0.01 Hz` – `120 MHz`):**
  - **Low frequency (`< 16 Hz`):** 64-bit hardware timer.
  - **Medium and high frequency (`≥ 16 Hz`):** Hardware PWM modulation with clock divider selection (`clkdiv = 250` for `16 Hz – 4 kHz` and `clkdiv = 1` for `≥ 4 kHz`).
- **Automatic Hybrid Frequency Meter (`10 kHz` Threshold):**
  - **High frequency (`≥ 10 kHz`):** Direct hardware measurement over a 100 ms window using two independent PWM slices extended to 32 bits via `PWM_IRQ_WRAP` interrupts (rising-edge counting on `PIN_MED` + 240 MHz high-level cycle counting on `PIN_DUTY`).
  - **Low frequency (`< 10 kHz`):** Direct reciprocal full-cycle measurement via edge capture in microseconds t<sub>high</sub> and t<sub>low</sub>.

### Visualization Software (C# Windows Forms)
- Automatic or manual serial port connection (**USB-CDC**).
- Remote control panel to configure **Frequency (Hz)** and **Duty Cycle (%)** in real time.
- Graphical and numerical display of frequency, period, high/low times, duty cycle, and cumulative event counter (with pause and reset options).
- Sample history export to Excel-compatible **CSV** format (UTF-8 with BOM encoding, `;` delimiter, and high decimal precision).

## Pinout Diagram

| Function | Physical Pin | GPIO | PWM Channel / Slice | Description |
| :--- | :---: | :---: | :---: | :--- |
| **Generator Output** | Pin 21 | **GPIO 16** | Slice 0 — Channel A | Generated PWM signal output (`3.3 V`). |
| **Frequency Input** | Pin 20 | **GPIO 15** | Slice 7 — Channel B | Rising-edge counting and time capture input. |
| **Duty Cycle Input** | Pin 17 | **GPIO 13** | Slice 6 — Channel B | High-level time measurement input (`240 MHz`). |
| **GND** | Pin 18 / 23 | **GND** | — | Common ground reference. |

> **Note for self-diagnostic tests (Loopback):** To measure the signal generated by the Pico itself, jumper **GPIO 16** to **GPIO 15** and **GPIO 13**.

## Serial Communication Protocol (USB-CDC)

### Commands PC &rarr; Raspberry Pi Pico
- `S,<frequency_hz>,<duty_percent>\n` — Configures the generator output (example: `S,1000.0,50.0`). Sending `0` as the frequency stops generation and forces the output low (`0 V`).
- Event counter control commands (pause, resume, and reset to zero).

### Telemetry Raspberry Pi Pico &rarr; PC
- **High-Frequency Frame (`≥ 10 kHz`):** `H,<window_pulses>,<delta_t_us>,<total_events>,<duty_percent>`
- **Low-Frequency Frame (`< 10 kHz`):** `T,<t_high_us>,<t_low_us>,<total_events>`
- **No-Signal Frame (Timeout):** `Z,0,0,<total_events>`

## Installation and Usage

### 1. Build and Flash the Firmware
1. Make sure you have the **Raspberry Pi Pico SDK** and **CMake** installed.
2. From the `firmware/` folder:
   ```bash
   mkdir build
   cd build
   cmake ..
   make -j4
   ```
3. Hold down the **BOOTSEL** button on the Raspberry Pi Pico while connecting it to your PC, and copy the generated `.uf2` file into the `RPI-RP2` drive.

### 2. Run the Software on Windows
1. Open `software/FrecuencimetroVisualizador.sln` in **Visual Studio** (with the .NET desktop development workload installed).
2. Build in **Release** (`x64`) mode or download the executable from the **Releases** section of this repository.
3. Select the COM port corresponding to the Pico, click **Connect**, and adjust the generator parameters or measure any external signal from `0 V` to `3.3 V`.

> **Electrical Warning:** The GPIO pins on the Raspberry Pi Pico operate exclusively at **3.3 V** and are not 5 V tolerant.
